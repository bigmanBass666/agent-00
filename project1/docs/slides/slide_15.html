工程规范：换一本书，只改一行配置

模块划分（每层可独立验证）

config.py

阈值 / 模型 / 路径

build_kb.py

提取 / 分块 / 向量化

rag.py

翻译 / 检索 / 生成

run_eval_v2.py

评测 / 判定 / 统计

换书三步

BOOK_PATH=新书.pdf python build_kb.py
→ validate_kb.py
→ run_eval_v2.py

多书用 KB_VECTORS / KB_CHUNKS 隔离，互不覆盖

交付与安全

  • 提示词独立成文件，可单独评审
  • API Key 走 .env + gitignore，仓库无明文
  • 一键流程：build → validate → eval → judge
  • 支持云部署（Procfile），可现场跑
