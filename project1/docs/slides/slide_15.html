换书流程（3 步）

BOOK_PATH=新书.pdf python build_kb.py
→ validate_kb.py 校验
→ run_eval_v2.py 跑评测

多书并存用 KB_VECTORS / KB_CHUNKS 环境变量隔离，互不覆盖

交付物与安全

  • 提示词独立成文件（prompt/system_prompt.txt），可单独评审
  • API Key 走 .env，已被 gitignore，仓库无明文
  • 代码注释 + README + 一键流程：build → validate → eval → judge
  • 支持云部署（Procfile），答辩可现场跑
