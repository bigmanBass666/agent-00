文档允许"自定义方案"，代价是需要教师确认（已备归类说明）

方案 组成 我们的判断
A 参考路径 DSH + SQLite FTS5 + BM25 与参考案例重复，关键词匹配对口语化提问不敏感
B 框架路线 ChromaDB/FAISS + LangChain 数据仅 159 块，框架抽象成本大于收益
C 自研（变体） 自研检索 + 直连 LLM API 链路短、每层可打印中间结果、便于归因 ← 我们的选择
D 低代码 Dify / FastGPT 无法体现技术深度

差异化

教材不同 · 检索方式不同（向量 + 词汇混合）· 未使用方案 A

归类说明

C 的变体：知识库用 json + npy 而非 SQLite；检索用 numpy 余弦 + 交叉编码器重排
