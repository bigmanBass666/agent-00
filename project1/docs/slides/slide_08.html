07 · REFUSAL GATES

拒答为什么必须两层：单靠阈值会漏，单靠 LLM 会飘

GATE 1

阈值层

检索分 < 0.3 且词汇分 < 0.85 → 直接拒答，不调模型。
实测被它拦下的题分数区间 0.001~0.06，省钱且零幻觉风险。

GATE 2

LLM 层

分数过线也要拦"看着相关、书里没有"的诱导题。
实证：Which protein powder brand should I buy? 检索分 0.579 高于阈值，靠 LLM 层识别为书外推荐问题拒答。

反向通道：别把该答的也拦了

表格 / 短事实类课内题的检索分天然偏低——词汇分 ≥ 0.85 时绕过阈值放行交给 LLM 判断， 避免"1 杯等于几汤匙"这种题被误杀。

结论：两层各拦一类问题，每一层都可以被单独测试。
