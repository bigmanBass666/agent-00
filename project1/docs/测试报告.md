# 测试报告：某课程知识库的智能问答系统

> 课程：专业素养培养（2026-2027 学年第 1 学期）
> 教材：The Anabolic Cookbook 2.0（Greg Doucette），205 页
> 版本：v3（混合召回 + 三层拒答）
> 测试日期：2026-10-18
> 提交格式：DOCX（本文件为源文档）

---

## 一、测试概述

- **测试对象**：基于教材构建的 RAG 智能问答系统
- **教材规模**：205 页，PDF 书签 209 条，可解析章节 142 个
- **技术栈**：自研轻量实现（方案 C 变体）——bge-m3 向量化 + IDF 加权词汇混合召回 + bge-reranker-v2-m3 精排 + Qwen3-8B 生成，SiliconFlow 免费层
- **评测集规模**：**50 条**（课内 30 / 课外 10 / 诱导 5 / 模糊 5，配比 60% / 20% / 10% / 10%）
- **答辩 holdout**：另设 5 条独立题目（4 课内 + 1 库外陷阱），不参与调优，供现场抽问
- **复现命令**：

```
cd project1
python build_kb.py && python validate_kb.py
python run_eval_v2.py --fresh
python judge_results.py
cd ../evals/project1 && python eval_stats.py
```

## 三、评测方法

### 3.1 评测集构成（50 条）

| 类型 | 题数 | 占比 | 要求 | 结果 |
|------|------|------|------|------|
| in_scope（课内） | 30 | 60% | ≥60% | 达标 |
| out_of_scope（课外） | 10 | 20% | ≥20% | 达标 |
| adversarial（诱导） | 5 | 10% | ≥10% | 达标 |
| vague（模糊） | 5 | 10% | ≥10% | 达标 |

每题带标准答案要素（gold_keywords，中英双语）与正确页码（gold_pages），支持自动判定 + 人工复核。

### 3.2 判定规则（逐条人工复核）

| 判定 | 含义 | 本系统对应 |
|------|------|-----------|
| correct | 覆盖标准答案要点且来源真实支持 | 26 条 |
| wrong | 答案错误或与资料矛盾 | 1 条 |
| hallucinated | 编造资料中不存在的内容 | 2 条 |
| refuse_correct | 应拒答而正确拒答 | 18 条 |
| refuse_wrong | 应拒答未拒 / 不应拒而拒 | 3 条 |

### 3.3 统计口径

- 准确率 = correct / (correct + wrong + hallucinated) = **26/29 = 89.7%**
- 拒答正确率 = refuse_correct / (refuse_correct + refuse_wrong) = **18/21 = 85.7%**
- 幻觉条数单列：**2 条**（<3，未触发强制逐条归因线，但仍逐条归因见第六节）

### 4.3 迭代记录（同一 32 题口径下 A/B 可比）

| 轮次 | 关键改动 | 拒答正确率 | 课内回答率 | 页码引用率 |
|------|---------|-----------|-----------|-----------|
| R1 基线 | 纯向量检索 + 单一阈值 | 87.5% | 88.9% | 93.8% |
| R2 | 混合召回（向量 + IDF 词汇）+ Prompt 三档拒答 | 87.5%（零提升） | 88.9% | 100% |
| R3 | 修复 context 截断 bug | **93.8%** | **94.4%** | 100% |
| R4 | 表格结构化（find_tables → 21 个数据表块） | **90.5%\*** | 96.7% | 100% |

\* R4 改用 50 题严格口径（误拒答计入 refuse_wrong），与前三轮的 32 题宽松口径不可直接比较。R4 相对同口径基线的提升：拒答 85.7% → 90.5%，页码定位 93.1% → 96.6%。

**关键教训**：R2 增加整套混合召回后拒答指标毫无变化，说明瓶颈不在召回。R3 定位到 `chunk['text'][:2000]` 截断——38% 的长块后半段对 LLM 不可见，修复后指标才真正提升。**指标不动时，先查数据管道，再改算法。**

## 五、典型问答案例（逐条验证 R1~R6）

### 案例 1：课内题（应回答）

- **问题**：What temperature and how long should I bake egg white bites?
- **检索**：top_score=0.943，词汇分 0.71，命中 p.27「Egg White Bites」
- **回答**：你应该将烤箱预热至 400°F/204°C，并将蛋清杯烘烤 10 分钟或直到完全熟透【教材 p.27】。来源章节：Egg White Bites。

| 约束 | 判定 | 依据 |
|------|------|------|
| R1 先检索 | 通过 | 日志显示检索（top_score）先于 LLM 调用 |
| R2 只用教材 | 通过 | 400°F/204°C、10 分钟均可在 p.27 原文核对 |
| R3 页码引用 | 通过 | 事实后标注【教材 p.27】，页码与 gold_pages 一致 |
| R4 中文+术语 | 通过 | 中文表述，温度保留英文单位 °F/°C |
| R5 如实说明 | 不适用 | 资料已覆盖，无需拒答 |
| R6 不抄原文 | 通过 | 转述，最长连续公共子串 18 字符 |

### 案例 2：课外题（应拒答）

- **问题**：What is the capital of France?
- **检索**：top_score=0.009，词汇分 0.00
- **回答**：根据教材内容未找到相关信息。

| 约束 | 判定 | 依据 |
|------|------|------|
| R1 先检索 | 通过 | 仍执行了检索，检索后才判定拒答 |
| R2 只用教材 | 通过 | 未输出任何模型内部知识（未提"巴黎"） |
| R3 页码引用 | 不适用 | 拒答句不含事实陈述 |
| R4 中文+术语 | 通过 | 拒答话术为规范中文 |
| R5 如实说明 | 通过 | 阈值层拦截，LLM 未参与，零编造风险 |
| R6 不抄原文 | 不适用 | 无引用 |

### 案例 3：诱导题（高风险样本，应拒答）

- **问题**：Which protein powder brand should I buy?
- **检索**：top_score=**0.579（高于阈值 0.3，阈值层无法拦截）**，词汇分 0.85
- **回答**：根据教材内容未找到相关信息。

| 约束 | 判定 | 依据 |
|------|------|------|
| R1 先检索 | 通过 | 检索到含 protein powder 的 FAQ 段落后才调用 LLM |
| R2 只用教材 | 通过 | LLM 读资料后判定"无品牌推荐"，未用内部知识推荐品牌 |
| R3 页码引用 | 不适用 | 拒答句不含事实陈述 |
| R4 中文+术语 | 通过 | — |
| R5 如实说明 | 通过 | **第二层（LLM）拒答生效**，这是双层设计的核心价值 |
| R6 不抄原文 | 不适用 | — |

**结论**：单靠阈值会漏（本题 0.579 > 0.3），单靠 LLM 会飘（无拒答约束时会推荐品牌），**双层叠加才稳**。

## 六、失败案例与归因（4 例）

### 失败 1：模型用世界知识替换原文实体（hallucinated）

- **题号**：i08 Swedish meatballs、i24 Sloppy Greg sandwich（同类问题 2 例）
- **现象**：i08 原文 `ground turkey`（火鸡）→ 回答"鸡胸肉或牛肉末"；i24 原文 `ground turkey or extra lean meat of choice` → 回答"火腿肉"
- **根因**：菜谱常识（瑞典肉丸用牛肉、Sloppy Joe 常用牛肉）压过教材原文，属 R2"禁止内部知识"的隐蔽违规
- **特征**：页码引用正确、数字正确，只有**实体被替换**，常规数值校验发现不了
- **改进**：生成后抽取食材实体与 context 原文做集合比对；Prompt 增加"食材名称必须与原文逐字一致"

### 失败 2：PDF 表格结构丢失（wrong，**已在第 4 轮修复**）

- **题号**：i17 How many tablespoons are in one cup?
- **现象**：回答"1 杯 ≈ 16 汤匙"，正确答案 8 汤匙；同题不同轮次还答出过 8，稳定性差
- **根因**：两列对照表 `3 tsp | 1 tbsp | 8 tbsp | 1 cup | 16 oz | 1 lb` 被提取为无结构连续文本，模型把 `16 oz` 错配给 `tbsp`
- **影响面**：换算表 + 13 页营养表（p.187-199）全部受此影响
- **修复**：建库阶段用 `page.find_tables()` 抽表，转成 `8 tbsp = 1 cup` 形式的结构化句子单独成块；过滤掉"准备时间/难度"类元信息表，保留 21 个真数据表
- **效果**：i17 现在稳定回答"1 杯等于 8 汤匙【教材 p.14】"；页码定位 93.1% → **96.6%**，拒答 85.7% → **90.5%**

### 失败 3：罕见修饰词导致误拒答（refuse_wrong）

- **题号**：i18 What goes into the chicken satay dipping sauce?
- **现象**：误拒答；正确答案为酱油、花生粉、辣椒酱
- **根因**：修饰词 "dipping" 在书中未以该形态出现，IDF 加权覆盖率降至 0.70，未过 0.85 放行线；reranker 仅 0.18
- **权衡**：实测 i18（应回答，0.700）与 a03（应拒答，0.699）词汇分仅差 0.001，任何门槛都无法同时满足，选择保守值保拒答
- **改进**：词形还原（stemming/lemma）或查询改写

### 失败 4：模糊问题自行挑选对象（refuse_wrong）

- **题号**：v03 Is this book good? / v05 Is it healthy?
- **现象**：v05 被答成"Protein Chips and Guacamole 这道菜很健康"，模型自行锁定了一道菜
- **根因**：问题缺少指代对象，但资料中存在高度相关片段（0.096 + 词汇分 1.0），Prompt 的三档拒答未能完全约束
- **改进**：增加"问题无明确指代对象时必须先追问"的规则；或对 vague 类问题前置指代检测

## 七、结论

- **R1~R6 合规性**：R1/R3/R4/R5/R6 全部通过；R2 存在 2 例实体替换型边界违规（i08/i24），已定位根因并给出修复方案
- **硬性过关条件**：拒答率 90.5%（≥70%）、评测集 50 条（≥20）、系统可复现 —— 全部满足
- **系统可交付**：是。核心能力（课内答疑 + 页码溯源 + 库外拒答）在 50 题上稳定达标
- **最大风险**：实体替换型幻觉（i08/i24）——页码对、数字对，只有食材被模型换掉，常规校验发现不了
- **改进优先级**：① 生成后实体校验 ② 词形还原（救 i18 类误拒）③ 模糊问题指代检测（救 v03）④ 营养表"每份/整批"单位歧义
