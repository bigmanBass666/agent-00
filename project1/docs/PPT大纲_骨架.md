## 第 3 页：技术选型对比
| 方案 | 描述 | 我们的选择 |
|------|------|-----------|
| A 参考路径 | LangChain + 向量库 | ✗（多样性扣分） |
| B 向量检索 | Embedding + Top-K | ✓ 轻量自研 |
| C 知识图谱 | 实体关系抽取 | ✗（复杂度高） |
| D 微调 | 模型训练 | ✗（成本高） |
- 选择理由：方案 B 最贴合需求，自研实现降低复杂度，额外加 reranker 精排提升质量

- 为什么两段式：粗召回保证召回率，精排保证相关性

## 第 7 页：R1~R6 行为约束设计
- R1：回答前必须检索（代码层面强制，检索结果为空直接拒答）
- R2：禁止内部知识（System Prompt 明确禁止 + 资料隔离）
- R3：页码引用【教材 p.XX】（分块时记录页码，Prompt 要求标注，自动检查覆盖率）
- R4：简单中文+保留英文术语（System Prompt 指令）
- R5：未覆盖如实说明（固定拒答句式 + 两层拒答）
- R6：不超过 3 句连续引用（System Prompt 指令 + 资料截断 2000 字）
