# 外部资料精选清单（项目一）

**规则**：标【必看】的内容评审时可能抽问；【选看】按兴趣。所有外部代码引用须在 README 注明来源。

## 一、官方文档

| 资料                                                               | 标注 | 看点                                                        |
|--------------------------------------------------------------------|------|-------------------------------------------------------------|
| LangChain 官方 Quickstart（python.langchain.com/docs/get_started） | 必看 | RAG 各组件的标准概念与命名，与你的骨架代码对应              |
| LlamaIndex 官方文档（docs.llamaindex.ai）                          | 选看 | 另一种实现思路，对比其与 LangChain 的概念差异（答辩加分点） |
| Chroma 使用指南（docs.trychroma.com）                              | 必看 | 持久化与检索接口，理解向量库的”最小可用集”                  |

## 二、论文

| 资料                                                                                                     | 标注 | 看点                                                           |
|----------------------------------------------------------------------------------------------------------|------|----------------------------------------------------------------|
| Lewis et al., 2020, Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks（arXiv:2005.11401） | 必看 | RAG 的原始论文，只读摘要与引言即可，知道”为什么检索能增强生成” |
| Prompt Engineering Guide（promptingguide.ai）中的 RAG 章节                                               | 必看 | 检索结果如何组织进 Prompt 的实用写法                           |

|-------------------------------------------------------------|------|----------------------------------------------|
