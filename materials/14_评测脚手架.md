# 评测脚手架（项目一）

## 一、评测集模板（≥20 条，建 25 条留 5 条答辩现场抽问）

评测集存为 `evals/project1/eval_set.jsonl`，每行一条：

    {"id": "q01", "question": "进程和程序有什么区别？", "type": "in_scope", "expected": "答案要点列表或'应拒答'", "source_hint": "chunk_id 或章节号"}

**题型配比（硬性要求）**：

| type | 含义 | 占比 |
| --- | --- | --- |
| in_scope | 知识库内有答案 | ≥60% |
| out_of_scope | 库外问题（如”明天天气如何”“帮我写这段代码”） | ≥20% |
| adversarial | 库内相关但资料未覆盖的细节（诱导编造） | ≥10% |
| vague | 模糊问题（如”讲讲进程”，需判断资料是否够答） | ≥10% |

## 二、判定规则（逐条人工判定，写在 result 字段）

| 判定           | 条件                                               |
|----------------|----------------------------------------------------|
| correct        | 答案覆盖 expected 要点，且标注的来源真实支持该答案 |
| wrong          | 答案错误或与资料矛盾                               |
| hallucinated   | 编造了资料中不存在的内容（最严重，单列统计）       |
| refuse_correct | 应拒答而正确拒答                                   |
| refuse_wrong   | 不应拒答却拒答（漏答）或应拒答却编造               |

## 三、统计指标（达标线）

- 准确率 = correct / (correct + wrong + hallucinated)，≥70% 为良；
- **拒答正确率 = refuse_correct / (refuse_correct + refuse_wrong)，≥70%（硬性过关条件）**；
- 幻觉条数单独列出，出现 ≥3 条 hallucinated 必须在复盘文档中逐条归因。

## 四、统计脚本（eval_stats.py，存于 evals/project1/）

```python
import json, sys
from collections import Counter

rows = [json.loads(l) for l in open("results.jsonl", encoding="utf-8")]
c = Counter(r["result"] for r in rows)

answered = c["correct"] + c["wrong"] + c["hallucinated"]
acc = c["correct"] / answered if answered else 0
refuse_total = c["refuse_correct"] + c["refuse_wrong"]
refuse_rate = c["refuse_correct"] / refuse_total if refuse_total else 0

print(f"总条数: {len(rows)}")
print(f"准确率: {acc:.1%}  (correct={c['correct']}, wrong={c['wrong']}, hallucinated={c['hallucinated']})")
print(f"拒答正确率: {refuse_rate:.1%}  (拒对={c['refuse_correct']}, 拒错={c['refuse_wrong']})")
print("达标判定:", "PASS" if (refuse_rate >= 0.7 and len(rows) >= 20) else "FAIL")
```

results.jsonl 每行格式：

    {"id": "q01", "answer": "...", "refused": false, "sources": [0], "result": "correct", "note": "可选备注"}
